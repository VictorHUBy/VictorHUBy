## Projetos em destaque

### [SIGSIF Importador de Aves](https://github.com/VictorHUBy/sigsif-importador-aves)
Extensão para Chrome e Edge que automatiza uma tarefa repetitiva de lançamento de diagnósticos a partir de texto. Um projeto criado para resolver um problema prático.
**Tecnologias:** JavaScript, extensões de navegador, DOM.

### [REA — Engenharia Reversa](https://github.com/VictorHUBy/rea-engenharia-reversa)
Guia multilíngue sobre engenharia reversa com ferramentas e agentes de IA. Organiza referências, explica conceitos e discute possibilidades e limitações.
**Temas:** engenharia reversa, Ghidra, IA.

### [BackEND — API de livros](https://github.com/VictorHUBy/BackEND)
Repositório de estudos de JavaScript e backend, com uma API REST para operações com livros e empréstimos.
**Tecnologias:** Node.js, Express, JavaScript.

### [Kairo — assistente digital](https://github.com/VictorHUBy/assistent-kairo)
Projeto em desenvolvimento de um companheiro digital para desktop, pensado para combinar conversa, memória e uma personalidade própria.
**Tecnologias planejadas:** React, TypeScript, Electron, Node.js e SQLite.

### [Oficina de Bicicletas](https://github.com/VictorHUBy/Oficina)
Aplicação de estudo com React para cadastrar e acompanhar ordens de serviço, marcar trabalhos como concluídos e visualizar valores em aberto.
**Tecnologias:** React, JavaScript, Vite.
